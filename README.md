# TNT Bow Mod

The TNT Bow Mod is a Minecraft mod that adds a new item to the game: the TNT Bow. This bow is crafted with TNT blocks around a regular bow, creating a unique and powerful weapon. The TNT Bow shoots explosive arrows that create a large explosion upon impact, making it a versatile tool for combat, mining, or just causing chaos in the game world.

## Install

1. Download the mod file (usually a .jar file) from the GitHub repository or the EnderDevelopment marketplace.
2. Place the downloaded file into the `mods` folder of your Minecraft instance. If you don't have a `mods` folder, create one in the root directory of your Minecraft installation.
3. Launch Minecraft and ensure that the mod is loaded correctly. You should see the TNT Bow in the Creative Mode inventory under the Combat tab.

## Use

1. Craft the TNT Bow by placing TNT blocks in a square pattern around a regular bow in the crafting grid. The recipe is as follows:
   ```
   T T
    T
    B
   ```
   Where `T` represents a TNT block and `B` represents a bow.
2. Once crafted, the TNT Bow can be used like any other bow. Right-click to pull back the bowstring and left-click to shoot an explosive arrow.
3. The explosive arrows will create a large explosion upon impact, dealing damage to nearby entities and breaking blocks in a wide radius.
